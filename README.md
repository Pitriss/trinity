# Trinity desktop stuff
This repo contains various things dedicated or connected to a [linux DE Trinity desktop](https://www.trinitydesktop.org/). Artwork, themes, scripts, whatever came to my mind and needs.

Tree structure should be self-explanatory.

Files prefixed "danix" are rescued theming pieces from old and long time abandoned czech linux distro Danix. I liked them so I put my effort into saving these files. They are most likely under GPL2 licence, unfortunatelly there is no way, how to confirm this, as none of these files contain any hint about licence.

All my work in this repo is under WTFPL licence, unless stated otherwise.
